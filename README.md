## Questions and problems

You can open an issue in this repo, but a **support ticket** at https://imbutus.com/support is the better route: it is tied to your account, so I can see your models, GPU sessions and billing, and it stays private. Use issues for things that are not account-specific — a mistake in a post, a broken link, or a general question.
